# Bangkok_Subsidence_Hotspot_Policy_Map

# 🗺️ Bangkok Subsidence Policy Map (Interactive Hotspot Map)

**โครงการปริญญานิพนธ์:** การวิเคราะห์แนวโน้มการทรุดตัวของแผ่นดินในกรุงเทพมหานครด้วยวิธี InSAR ร่วมกับข้อมูลการใช้น้ำบาดาล
**ภาควิชา:** วิศวกรรมโยธา คณะวิศวกรรมศาสตร์ มหาวิทยาลัยเทคโนโลยีพระจอมเกล้าธนบุรี (ปีการศึกษา 2568)

โปรเจกต์นี้คือเครื่องมือสร้างแผนที่เชิงนโยบายแบบโต้ตอบ (Interactive Web Map) ที่พัฒนาด้วย Python (Folium) เพื่อบูรณาการผลลัพธ์จากแบบจำลอง Machine Learning (Random Forest และ XGBoost) เข้ากับข้อมูลการทรุดตัวจริงจากดาวเทียม InSAR และข้อมูลทางอุทกธรณีวิทยา เพื่อใช้เป็นเครื่องมือสนับสนุนการตัดสินใจเชิงนโยบายและการเฝ้าระวังโครงสร้างพื้นฐาน

---

## ✨ ฟังก์ชันและคุณสมบัติหลัก (Core Features)

### 1. 📊 Dual-Model Explainability (การอธิบายผลแบบจำลองคู่)
* **Side-by-Side Comparison:** นำเสนอผลการวิเคราะห์ความสำคัญของตัวแปร (SHAP Values) จากทั้งโมเดล Random Forest (Bagging) และ XGBoost (Boosting) มาเปรียบเทียบกันแบบเคียงข้าง
* **CSS Donut Charts:** สร้างกราฟวงแหวน (Donut Chart) ด้วย Pure CSS เพื่อแสดงสัดส่วนอิทธิพลของกลุ่มตัวแปรน้ำบาดาล (Groundwater Impact) เทียบกับปัจจัยอื่นๆ 
* **Collapsible Sub-factors:** ระบบพับเก็บตารางตัวแปรย่อย (Lag1-Lag5, Clay Thickness, NDBI) เพื่อให้ UI ดูสะอาดตา แต่ยังคงความโปร่งใสของข้อมูลให้ผู้ใช้สืบค้นได้

### 2. 🚨 Engineering Thresholds & Color Logic (เกณฑ์เตือนภัยทางวิศวกรรม)
ระบบวิเคราะห์และคัดกรองความเสี่ยงของแต่ละสถานีอัตโนมัติ โดยอิงจากค่าการทรุดตัวสะสม (Cumulative Subsidence) ตามหลักวิศวกรรมปฐพีกลศาสตร์:
* 🟢 **ปกติ (Stable):** ทรุดตัวสะสม 0 - 50 mm
* 🟠 **เฝ้าระวัง (Watch):** ทรุดตัวสะสม > 50 mm (พื้นที่เริ่มเข้าสู่สภาวะเสียสมดุล)
* 🔴 **เตือนภัยวิกฤต (Warning):** ทรุดตัวสะสม > 100 mm (เสี่ยงต่อความเสียหายของท่อประปาและสาธารณูปโภคขั้นรุนแรง)

### 3. 🎯 Automated Anomaly Detection (ระบบตรวจจับความผิดปกติ)
* คำนวณค่าความคลาดเคลื่อนสมบูรณ์ (Mean Absolute Error: MAE) ของแต่ละสถานีแบบ Real-time
* **🌟 Best Fit Tag:** ติดป้ายสถานีที่แบบจำลองทำนายได้แม่นยำสูง (Error < 5 mm)
* **🚨 Worst Anomaly Tag:** ติดป้ายเตือนสถานีที่มีความคลาดเคลื่อนสูง (Error > 35 mm) เพื่อชี้เป้าให้เห็นถึงอิทธิพลของตัวแปรแฝง (Omitted Variables) เช่น น้ำหนักบรรทุกอาคาร หรือการสูบน้ำเถื่อน

### 4. 📱 Responsive UI & Academic Integration (ส่วนติดต่อผู้ใช้ที่รองรับทุกหน้าจอ)
* **Fully Responsive:** ระบบปรับขนาด Pop-up และจัดเรียงกราฟใหม่ให้เหมาะสมกับการแสดงผลบน โทรศัพท์มือถือ แท็บเล็ต และคอมพิวเตอร์ โดยอัตโนมัติ
* **Floating Manual:** กล่องคู่มือที่อธิบายทฤษฎีทางวิศวกรรม (เช่น Inelastic Consolidation, Delayed Compression) และข้อจำกัดของแบบจำลอง (Concept Drift) 
* **Toggle Watermark:** ลายน้ำวิทยานิพนธ์แบบซ่อน/แสดงได้ (Toggle 'i' Button) เพื่อระบุผู้จัดทำโดยไม่บดบังแผนที่
* **Permanent Station Labels:** ป้ายชื่อสถานีโปร่งใส ลอยอยู่เหนือจุดพิกัดตลอดเวลา เพื่อการสืบค้นที่รวดเร็ว

## 📁 ข้อมูลนำเข้า (Data Inputs)
โปรแกรมต้องการไฟล์ CSV 3 ไฟล์สำหรับการประมวลผล:
1. `Hotspot_Data_[Year]_RF.csv` (ผลลัพธ์ SHAP จาก Random Forest)
2. `Hotspot_Data_[Year]_XG.csv` (ผลลัพธ์ SHAP จาก XGBoost)
3. `WellDATA.csv` (ฐานข้อมูลหลักของบ่อบาดาล เช่น ชื่อบ่อ, ความหนาดินเหนียว)

## 🛠️ วิธีการใช้งาน (How to run)
1. ติดตั้งไลบรารีที่จำเป็น: `pip install pandas folium branca numpy`
2. รันสคริปต์ `Bangkok_Hotspot_Map.py` 
3. หน้าต่าง GUI จะปรากฏขึ้น ให้เลือกไฟล์ CSV นำเข้าทั้ง 3 ช่อง
4. กดปุ่ม `GENERATE OFFICIAL POLICY MAP`
5. ระบบจะสร้างไฟล์ `Bangkok_Final_Thesis_Map.html` ซึ่งสามารถนำไปโฮสต์บน GitHub Pages ได้ทันที
